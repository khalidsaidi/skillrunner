# SkillRunner Engine

Core runtime engine used by `@khalidsaidi/skillrunner`.

This package powers:

- SKILL.md parsing
- registry resolution/search/install support
- run planning and execution
- script guardrails
- prerequisite preflight checks
- run artifact generation

For end-user usage, install the CLI package instead:

```bash
npm i -g @khalidsaidi/skillrunner
```

Repository: <https://github.com/khalidsaidi/skillrunner>
