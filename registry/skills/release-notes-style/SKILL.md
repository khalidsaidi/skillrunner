# Release Notes Style

- **Headline**: Version and date
- **Highlights**: 2-3 main changes
- **Added/Changed/Fixed/Removed** sections
- **Breaking changes**: Call out explicitly with migration steps
- **Upgrade**: Brief upgrade instructions if needed
