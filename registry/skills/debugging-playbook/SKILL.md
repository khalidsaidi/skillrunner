# Debugging Playbook

1. **Reproduce**: Minimize steps; note environment
2. **Isolate**: Bisect, narrow scope
3. **Inspect**: Logs, breakpoints, stack traces
4. **Hypothesize**: Form and rank hypotheses
5. **Validate**: Test one variable at a time
6. **Fix & regression**: Add test to prevent recurrence
